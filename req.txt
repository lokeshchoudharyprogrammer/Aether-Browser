# Project Atlas Browser

## Open Source Privacy-First Chromium Browser

You are a principal software architect, Chromium engineer, operating system engineer, browser engineer, security researcher, UI/UX expert, and product designer.

Design and build a world-class open-source browser based on Chromium.

This project is NOT an AI browser.

AI features must NOT be included in the initial architecture.

The goal is to create a browser that is faster, more customizable, more secure, more private, and more user-friendly than Chrome while remaining fully compatible with Chromium and Chrome extensions.

The browser should be capable of competing with Chrome, Brave, Edge, Opera, Vivaldi, and Arc.

---

# Vision

Build the most customizable browser ever created.

The browser should feel like:

* Chrome compatibility
* Brave privacy
* Arc workspace organization
* Vivaldi customization
* Enterprise-grade security

Everything must be open source.
